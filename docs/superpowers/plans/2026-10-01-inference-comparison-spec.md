# 推論輸出與三組參數比較需求

1. 先修改新陰影推論程式的圖片輸出：只有分割塗色，不顯示信心分數、D/R 文字、偵測框或輪廓線。
2. 這個顯示調整維持模型、來源、推論參數、遮罩內容、類別顏色與 alpha=0.35 不變；JSON 的分數與類別資料保留，供比較使用。
3. 完成並實際輸出圖片後，再做三組參數測試：只調陰影增強、只調一般推論參數、陰影與一般參數搭配。
4. 三组使用 predict-2.py 中已啟用的模型、圖片與一般推論基準，每組保留原圖基準；所有比較圖片使用相同的純塗色方法。
5. 自動依序執行每版；每次建立時間資料夾，組別、版本、模型、來源分開存放。保存參數、日誌、成功失敗狀態、耗時與預測資料。
6. 產生各組比較圖與跨組總覽。圖片內只保留塗色；版本與參數標示在圖片外。
7. 不以預測數量代替準確率，不在缺少標註時宣稱最佳版本。
8. 使用現有 Windows/PowerShell、yolov11 Python 環境與本地 GPU，不增加依賴。
9. 預覽後追加：修正最右側橘色柱子的 R 誤檢。用只匹配該圖片完整路徑的背景排除區，保留貨櫃本體；所有比較版本使用同一份設定，清楚註明並非模型能力提升。
10. 追加漏檢位置：左側 MSC 附近凹陷與右下陰影。使用提供的 CBHU0708054-A.xml 核對框標記，嘗試局部背景裁切與重疊放大；只保存模型實際推論結果，不能將標記當作預測或以塗色增加宣稱成功。
11. 使用者要求繼續核查訓練標註與模型：核對新舊標註、類別順序、資料切分、權重保存的訓練設定和驗證紀錄；區分本機資料的已知事實與 Linux 原始訓練來源的未確認事項。
12. 本輪輸出可重跑的核查工具、逐項補標清單與報告。原資料、權重及推論預設保持原樣；不把 XML 方框改成分割真值，不在缺乏真實輪廓與確認過的資料切分時重訓。
